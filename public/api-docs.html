Vulnerabilities

Create, retrieve, update and delete vulnerabilities.

5 endpoints
GET /api/vulnerabilities ↗

Retrieve all vulnerabilities.

Returns a JSON object containing the vulnerabilities array. Open endpoint ↗
POST /api/vulnerabilities ↗

Create a new vulnerability record.

EXAMPLE REQUEST BODY
{
  "title": "Example vulnerability",
  "description": "Example description",
  "cve": "CVE-2026-0001",
  "cvss": 7.5,
  "contextual_severity": "High",
  "source": "OpenVAS",
  "date_discovered": "2026-10-13",
  "status": "Open"
}
GET /api/vulnerabilities/:vulnerability_id ↗

Retrieve a single vulnerability by its ID.

Replace :vulnerability_id with the record ID. Try ID 1 ↗
PATCH /api/vulnerabilities/:vulnerability_id ↗

Update an existing vulnerability's details.

EXAMPLE REQUEST BODY
{
  "contextual_severity": "Critical"
}
PATCH /api/vulnerabilities/:vulnerability_id/status ↗

Change the status of a vulnerability.

EXAMPLE REQUEST BODY
{
  "status": "Resolved"
}
DELETE /api/vulnerabilities/:vulnerability_id ↗

Delete a vulnerability by its ID.

This endpoint modifies data. Use an API client to send a DELETE request.
